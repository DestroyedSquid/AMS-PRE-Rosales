# Sistema de Gestión de Pedidos - Tienda Rosales (AMS-PRE)

## Descripción
Diseño e implementación de un sistema centralizado de gestión de pedidos en línea, orientado a optimizar la relación comercial entre los usuarios y el catálogo de productos[cite: 1].

## Objetivo
Desarrollar un sistema de gestión de pedidos con un 100% de integridad referencial entre usuarios, productos y órdenes, garantizando tiempos de respuesta en la creación de pedidos inferiores a 2 segundos[cite: 1].

## Módulos del Sistema[cite: 1]
* **Gestión de Usuarios (users):** Registro y consulta básica (id, name, email).
* **Gestión de Productos (products):** Catálogo de productos activos (id, name, price).
* **Procesamiento de Pedidos (orders):** Creación de órdenes (user_id, product_id, quantity, order_date) y consulta de historial.

## Estructura del Repositorio
* `/PreExamen2RosalesAMS`: Contiene los archivos fuente de PlantUML (Casos de uso, Actividades, Clases, ER).
* `/JIRA`: Contiene las capturas de pantalla de la gestión del proyecto en Jira (Backlog, Sprints, Tablero Scrum y Gráficas de estado).
